Guide

Guide de connexion

IP Java : play.arkos.fr
Port Bedrock : 19132
Version recommandée : 1.21.8

ARKOS est pensé pour offrir une première connexion claire, rapide et immersive. À l'arrivée, tu découvriras un spawn forestier, un parcours de présentation, des quêtes d'introduction et les principaux accès vers l'économie, les métiers et les événements.

Le portail web te permet également de suivre les actualités, de voter, d'accéder à la boutique et, à terme, de relier ton profil Minecraft à ton compte web pour suivre ta progression plus finement.

Premiers objectifs

  • Rejoins le tutoriel d'arrivée
  • Choisis un métier
  • Récupère tes quêtes quotidiennes
  • Vote pour débloquer tes premières récompenses
  • Rejoins le Discord communautaire
