Carte du serveur

Prépare l'intégration BlueMap / Dynmap

La page est prête à recevoir une iframe sécurisée, un reverse proxy ou une sous-route dédiée vers ta carte web Minecraft.

Zone d'intégration

Insère ici l'URL BlueMap ou Dynmap via un reverse proxy HTTPS. Exemple futur : https://map.arkos.local

Bonnes pratiques

HTTPS
Expose la carte via le même tunnel ou un sous-domaine Cloudflare.
Reverse proxy
Évite les appels localhost côté navigateur.
Navigation cohérente
La carte devient une page officielle du portail.
