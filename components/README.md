- composants visuels réutilisables
- templates admin/public
- blocs de cartes, tableaux, compteurs, toasts

Dans cette version statique, la mutualisation se fait surtout via :

- `assets/themes/rune/css/style19c1.css`
- `assets/themes/rune/css/admin19c1.css`
- `assets/themes/rune/js/app19c1.js`
- `assets/themes/rune/js/admin19c1.js`
